# Study Tracker (PWA)

A mobile-first bilingual (Bangla/English) study tracker.

## Features
- Custom subject folders and colors
- Date-based study records per subject
- Study timer that records completed sessions
- Bangla / English interface
- Monthly progress by subject and day
- Open PDF and text files; create notes and print/save them as PDF
- Daily study target (default 120 minutes)
- Local data storage and JSON backup/restore
- Installable PWA with offline caching after first visit

## Publish on GitHub Pages
1. Upload the contents of this folder (not the ZIP itself) to the root of your repository.
2. In Settings > Pages, select Deploy from a branch, branch `main`, folder `/(root)`, then Save.
3. Open the published URL in Chrome and choose Install app / Add to Home screen.

## Notes
- Data is stored in this browser on this device. Use Export regularly for backups.
- DOC/DOCX opening depends on a compatible app installed on your phone. PDF and plain-text preview are built in.
- This is a web app (PWA), not a native APK.
