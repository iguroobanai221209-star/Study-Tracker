STUDY TRACKER — Mobile PWA

Included:
- Daily study goal and progress
- Focus timer (25/50/custom minutes)
- Study session history for today
- Task checklist
- Editable subject list
- Local device storage
- Backup export/import
- Offline caching after first successful visit

HOW TO INSTALL ON ANDROID:
1. Upload the contents of this folder to a static HTTPS host (for example GitHub Pages).
2. Open the published HTTPS address in Chrome on your Android phone.
3. Open Chrome ⋮ menu > Install app (or Add to Home screen).
4. Launch Study Tracker from your home screen.

IMPORTANT:
- This is a Progressive Web App, not an APK.
- It must be hosted on HTTPS for proper installation/service-worker offline support.
- Your study data is stored in the browser on this phone. Use Settings > Export regularly.
- Do not delete Chrome site data unless you have a backup.
